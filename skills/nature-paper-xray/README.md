# `nature-paper-xray` 技能

[English](README_EN.md)

`nature-paper-xray` 把一篇给定论文读到能复述作者的推理：他当初卡在哪、押了什么、哪个设计是承重的、公式在一组具体数字上长什么样、证据到底够到哪儿。它不是摘要，不是翻译，也不是审稿。

## 适合用它做什么

- 组会、读书会或答辩前，把一篇论文真正读懂并讲得出来。
- 要在别人的工作上继续做，先弄清它到底做了什么、留下什么缺口。
- 吃透一篇方法论文的公式，包括每个符号的形状含义和一个能手算的小例子。
- 读一篇结果很漂亮的论文，先看清它的对照条件、消融和适用范围再决定信多少。
- 审稿或写相关工作之前的准备：把论文的机制和证据边界先理清楚。

## 典型请求

- “帮我精读这篇论文，我想知道作者当初是怎么想到这个设计的。”
- “这个公式每一项是什么意思？给我一个能自己算一遍的例子。”
- “这篇论文的第一张图想让我相信什么？站得住吗？”
- “它的基线对比公平吗？有没有只在测试集上挑超参？”
- “论文里哪些设计是承重的，哪些拿掉也不影响结论？”

## 你需要提供

- 论文本体：PDF、arXiv 编号或链接、出版社 HTML 页，或者直接粘贴正文。
- 附录和补充材料（有就一起给，附录里常有正文不放的消融和真实搜索范围）。
- 你的目的：只是读懂、要写相关工作、要审稿、还是要在组会上讲——这决定详细程度。
- 可选：论文的官方代码仓库。代码会暴露论文没写的归一化、预热、数据过滤，有时性能恰恰来自那里。

## 产出

一份 Markdown 长文，按这个顺序：

1. 论文真正主张什么（撇开它自己的宣传措辞）。
2. 还原出来的研究路径：卡在哪、押了什么、证据是什么。
3. 承重判定：逐个组件说明拿掉会不会塌，以及支撑这个判断的证据。
4. 关键公式的可算例子。
5. 证据边界：结果建立了什么、没建立什么。
6. 读完能带走什么、还有哪些问题开着。

## 边界

- **只读不判。** 它报告论文做了什么、证据够到哪儿，不评分、不排名、不判录用成熟度或新颖性——那是 `nature-reviewer`。
- 它不提炼写作范式，不产出可复用的行文模板。
- 它不做全文翻译或中英对照阅读。
- 它不检索文献、不核验引用、不替论文补引用。
- 它不代写正文。要写相关工作或做定位时，把读出来的东西交给 `nature-writing`。
- 论文没报告的事就写“论文没有报告”，不用常识补一个看着合理的数字。

## 相关技能

| 技能 | 分工 |
|------|------|
| `nature-reviewer` | 从审稿人视角给出评审结论、分级意见和评分；本技能只提供输入 |
| `nature-reader` | 全文翻译与中英对照阅读稿；本技能不翻译 |
| `nature-writing` | 起草与重构手稿章节；本技能不写正文 |
| `nature-academic-search` | 检索相关工作与文献；本技能不联网找文献 |
| `nature-ref-verifier` | 核验引用是否存在、元数据是否正确 |
